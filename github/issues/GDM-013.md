## Scope

- Fetch permitted audio through the adapter and implement loading/playing/retry states.

## Acceptance criteria

- [ ] Audio starts only from explicit user action and respects size/MIME/duration bounds.
- [ ] Failure, corrupt data, resume and repeated-tap cases never silently replace content or mark progress.
- [ ] Web and native playback paths are exercised with permitted test clips; real recitation review is not claimed.
