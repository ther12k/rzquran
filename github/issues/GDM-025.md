## Scope

- Implement internal candidate/evidence checks, content-mode/environment constraints and an optional pilot gate evaluator.
- Provide kill switch, old-route fallback and staging-grant disable/revoke procedure.

## Acceptance criteria

- [ ] Missing/invalid approvals and production pairing attempts fail closed in evaluator tests.
- [ ] Rollback preserves progress and restores the old web route without exposing unapproved content.
- [ ] Tool documentation explicitly distinguishes this task from GDM-026/031/032 execution and owner decisions.

## Verification and evidence

Execute QA-39 from the [test plan](../../qa/test-plan.md). Attach commit/build/content identifiers, actual commands and outcomes, relevant artifact paths/hashes, and explicitly unexecuted checks using the [evidence template](../../qa/evidence-template.md). ## Exclusions

No unapproved external deployment, fabricated evidence, unrelated platform rewrite, hidden scope narrowing, production native login, app-store publication, or native iOS completion claim. Passing engineering checks does not imply human approval. Follow [agent rules](../../AGENTS.md) and [scope](../../product/scope.md).
