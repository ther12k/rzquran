## Scope

- Run Android Chrome, iPhone Safari and native Android on named physical devices.
- Capture layouts at agreed widths and actual device settings; review audio and assistive alternatives.

## Acceptance criteria

- [ ] Required layout, interaction, interruption and HTML accessibility checks have evidence tied to the candidate.
- [ ] Arabic/fixture rendering and audio limitations are separated from human curriculum approval.
- [ ] Unavailable devices/checks are explicit blockers, not silently assumed pass; iOS native is not claimed.

## Verification and evidence

Execute QA-37 from the [test plan](../../qa/test-plan.md). Attach commit/build/content identifiers, actual commands and outcomes, relevant artifact paths/hashes, and explicitly unexecuted checks using the [evidence template](../../qa/evidence-template.md). For human gates and pilots, record actual external evidence; code or a template cannot supply it.

## Exclusions

No unapproved external deployment, fabricated evidence, unrelated platform rewrite, hidden scope narrowing, production native login, app-store publication, or native iOS completion claim. Passing engineering checks does not imply human approval. Follow [agent rules](../../AGENTS.md) and [scope](../../product/scope.md).
